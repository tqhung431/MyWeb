About Chill Corner

Chill Corner is the first stage of Nook: a single static page made only of HTML, CSS and JavaScript. No server code, no database, no build step.

How it works

  • HTML describes the content: headings, buttons, the timer.
  • CSS lays it out, mobile-first, with a dark and light theme.
  • JavaScript reacts to clicks, counts down the timer and makes the sounds.

Credits and licences

  • All sounds are generated in your browser with the Web Audio API. No recorded music or sound files are used, so there is nothing to license.
  • Icons are standard Unicode emoji, drawn by your device's own font.
  • Fonts: your system's default font (no web fonts downloaded).
  • Code: written for Nook.
